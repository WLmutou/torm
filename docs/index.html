快速开始

在你的 Cargo.toml 中添加依赖并开始。

  Cargo.toml
[dependencies]
torm = "0.2"
tokio = { version = "1", features = ["full"] }
  src/main.rs
use torm::db::database::Database;
use torm::orm::model::Model;
use torm_derive::Model;

// 定义模型
#[derive(Model)]
struct User {
    #[id (auto_increment)]
    id: i64,
    name: String,
    age: Option<i32>,
}

#[tokio::main]
async fn main() -> torm::db::error::Result<()> {
    // 连接数据库（MySQL / PostgreSQL / SQLite 通用）
    let db = Database::mysql("127.0.0.1", 3306, "mydb", "root", "pass").await?;

    // 插入
    let user = User { id: 0, name: "Alice".into(), age: Some(25) };
    user.insert(&db).await?;

    // 查询
    let users = User::query(&db).await?;
    for u in users { println!("{:?}", u.name); }
    Ok(())
}

数据库迁移工具

内置 CLI 工具，在数据库之间迁移表结构与数据。

工具迁移方向示例
mysql2postgresql MySQL → PostgreSQL --mhost 127.0.0.1 --mport 3306 --mdb mydb ...
postgresql2mysql PostgreSQL → MySQL --phost 127.0.0.1 --pport 5432 --pdb mydb ...
sqlite2postgres SQLite → PostgreSQL ./sqlite2postgres data.db --phost ...
postgres2sqlite PostgreSQL → SQLite ./postgres2sqlite out.db --phost ...
  迁移示例
# MySQL → PostgreSQL（不指定 --tables 默认迁移全部表）
./target/release/mysql2postgresql \
  --mhost 127.0.0.1 --mport 3306 --mdb mydb --muser root --mpass pw \
  --phost 127.0.0.1 --pport 5432 --pdb mydb --puser postgres --ppass pw

# 可选参数：--tables t1,t2 / --batch 1000 / --create-only / --data-only

核心 API

统一的抽象层，一套代码访问多种数据库。

模块说明
db::database统一 Database / Transaction 抽象，MySQL / PostgreSQL / SQLite 通用
orm::model模型 trait 与 #[derive(Model)] 派生宏
orm::query链式查询构建器：Where / Order / Pagination
orm::advanced_query高级查询：Join / Aggregation / Union / Subquery
orm::relations关联关系：belongs_to / has_many 等
orm::migrationSchema 迁移工具
db::pool连接池
monitoring日志、SQL 监控与性能统计
